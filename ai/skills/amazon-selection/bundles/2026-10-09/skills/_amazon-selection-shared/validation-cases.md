这是规则回归用例，不是实盘结果或通过率提升证明。更新共享规则后，按完整文件逐例推导决策和阻塞原因；数字仅为构造样本。检查入口、类型规则和输出合同是否得出一致结果，不用字符串匹配代替商业判断。

新增询价分层与方向回归（2026-10-08）：

- 50行中40行严格A/B，受控试询与C档并集10行：可计50；并集11行时超额行暂不计交付完成数。

- 身份、目标pack、自然需求、风险/IP、包装或零采购经济性任一待补/失败：不得使用受控试询。
- 日常核心词有12个月但精确市场父体已证实>50：预检直接分流，不继续完整趋势和评论深抓。
- 季节精确关键词仅18个月，但精确产品市场和3个独立ASIN有两个完整一致周期：类型人工复核，其他询价作用域全部通过时可进入受控试询；只有宽泛类目双周期仍进观察池。
- 节日月度双周期完整但缺两周期日/周P10–P90：无论长短窗口都进观察池，不进入严格或受控询价。
- 热点爆发只有月度趋势：观察池；稳定装机盘滤芯有12个月装机代理、替换需求和开放售后证据时，改走`AFTERMARKET_INSTALLED_BASE`并补日常/消耗主类型，不冒充热点通过。
- 消耗标签证据不足，但目标200件pack自身销量、自然入口、主类型和经济性全部通过：可以按`PACK_SIZE_OPPORTUNITY`询价；不得授予消耗品标签。
- 同一购买问题的100PCS和200PCS只有件数不同：默认只计证据更强的一档；买家场景、价格带和目标子体需求均独立时才允许两个机会。

## 1. 阶段、记忆与转路

新增空运路径回归（2026-10-08，均为构造输入）：

- 正常节点迟到但空运计划含剩余开发、处理5天、到接收10天、可售准备及14天缓冲；剩余有效需求、首批、经济性和其他询价门槛均通过：可按空运路径进入询价，实际利润仍待人工询价，不改写为按期完成。
- 季节已开始但空运后的需求仍可证明：只按剩余需求核验，不能仅因错过季节开始否决，也不能用整季销量给后段外推。
- 空运可售时只剩清仓尾流，首批无法合理消化或MOQ过大：路径不通过。
- 空运后利润29%或单件贡献利润USD0.99：实际利润不通过，即使次年预计盈利。
- 空运周期10天含清关和FBA接收：不重复加这两段；剩余打样或接收后可售准备未知不能填0。
- 节日缺两周期日周证据、空运费率缺失或包装置信度D：待补，不计quote_ready。
- 常规过早观察期：不使用空运路径提前开发；正常路径本来成立则不受空运失败影响。
- 首年可询价但未有实际销量：学习计划不是验证成果；跨年库存未计仓储损耗不建议留存；次年费用需求须重核。
- 同一候选比较海运和空运：保留两个情景，只计一个独立机会。
- 只修改路径规则：不创建Goal、不调用Sorftime、不恢复选品、不采购或联系供应商。

## 2. 市场规则

- 10品牌均分销售额，Top3=30%，其余全部市场条件成立且有独立新品自然进入：分散/蓝海标签不通过；market可通过，不能因30%单独否决。用户选择冷门蓝海策略时该标签仍阻塞launch。
- Top3=18%但只有购买标记、无自然位：market不得通过，低集中不能补齐自然证据。
- 完整可评估E的三月中位销量为[0,0,5,10,15,20,40,50,60,70]；看销量前按规格/场景定义T为对应后5个独立父ASIN，至少2个经营主体，T销量[20,40,50,60,70]：E的P25=6.25用于诊断；T的P25=40用于目标预测。只有其他条件完整时市场才可通过。若看销量后挑后5个，则不允许此预测。
- T原定5个父ASIN，1个未知销量：不得删掉未知后给通过预测；forecast_coverage=4/5，预测资格待补。
- 5个子体全部在同一父体/同一卖家：不能当5个独立预测或进入样本。
- 仅2个同配置Offer，但有同用途成交、关键规格需求和供应方案：组合证据人工研究；不得自动通过市场/开发，也不能用父体销量证明目标pack。
- 50+购买、2条评价：可作需求线索；上架日、自然归因、三个月销量和利润均不得推定。没有标记不算0。
- 5个初始定义的T中存在真实零销量：保留0；不足3个完整月的样本单列，不能伪造零或外推90天销量。

## 3. 费用与底线

- 英国包装40×30×5cm、800g：不因40cm自动失败；按实际类目/费档/体积重和利润验证。
- 展开直径25cm但未取得包装三边：不能直接判包装超档；费用待补。
- 英国33×23×2.5cm、450g：低价费率卡标准信封行必须保留460g上限。公开资格页与费率行不一致，未得Fee Preview确认前低价资格待核验；可用普通信封费作有标注的保守研究情景。
- 英国大/超大信封900g：低价行上限保存960g；不自动享受优惠。小包裹401g：不落入低价小包裹400g行。
- 英国轻信封40g基础£1.50：适用时有效£1.5225，显示£1.52；未提前四舍五入进入利润公式。
- 德国CEP未知：DE_ONLY已经含差额，不能再加€0.26。日本档位重叠、加拿大体积重缺参数继续需计算器。
- 采购51元、包装2001g、完整贡献利润0.99美元、利润率29.9%：任一项失败均不允许launch通过。售价严格>USD4.99等值、预计自身月销>=30继续保留。
- FBA占售价31%但完整利润底线通过：不能单因31%淘汰。未知税费/采购不得填0创造利润。
- 市场通过、1688商品卡显示低价，但没有人工实际询价和最终包装三边/实重：`quote_input_status=待人工填写`、`profit_validation_status=待人工询价`、launch待补，不生成可执行运营策略。
- 人工报价按100件阶梯，但目标首批与目标Offer使用不同pack或材质：`QUOTE_CONFIGURATION_MISMATCH`、实际利润数据异常，不能择取较低单价继续计算。
- 英国人工填写最终包装30×20×5cm、实重0.7kg，所选渠道除数6000、费率40元/kg：体积重0.5kg、计费重0.7kg、头程28元；不得按1kg进位。若价格表条件不同，以当前有效表为准。
- 日本或加拿大头程费率仍未补齐：即使采购和包装实测齐全，实际利润仍为`待补费用`，不得填0放行。
- 实际利润不通过但market通过：保留market结论，输出达到门槛所需的最高采购价/最低售价/pack或尺寸重量敏感项；`operating_strategy_status=未就绪`。
- 实际利润、市场、类型、时机、供应和风险全部通过：才可生成正常价、保本价、30%利润底价、小批量建议及15/30/60/90天运营里程碑；仍不自动采购或联系供应商。

## 4. 评论与低成本改进

- 只抓一个父体的一条1星“物流晚到”：不能认定产品缺陷，不生成结构改进结论；标记覆盖不足和非供应链可控。
- 三个独立父ASIN的近期评论反复出现同一尺寸公差问题，目标Offer确实同规格：允许进入改进设计；仍须保留变体归属、样本量、时间和正向评价对照。
- 低星集中在父体的另一尺寸子体：标记`REVIEW_VARIATION_CONTAMINATION`，不得转嫁给目标Offer。
- 存在可信可改进缺陷：原则上生成至少3个结构不同的方案并说明成本、尺寸重量、FBA、合规/IP和验收方法；不能用三种同义文案凑数。
- 竞品没有重复且可控的缺陷：`review_driven_improvement_status=不适用`并说明不改理由；不得为了差异化强制增加部件或成本。
- 改进需要新模具、明显增重或新增认证，且利润/交期不再通过：即使买家感知强也不能作为低成本目标方案。
- 人工报价未包含选定改进，或报价材质与改进规格不一致：`QUOTE_CONFIGURATION_MISMATCH`，实际利润不得通过。
- 实际报价包含改进且利润仍通过，但尚无样品验收方法：可以完成利润计算，开发终审仍待补验收方案，运营卖点不得声称问题已经解决。

## 5. 独立效果验证

使用稳定candidate_id和同站去重的机会数；同时报告提交配置数。分开研究复核和开发终审，不混分母。
- 提交人工通过率 = 人工通过数 / 全部提交数（包含待审）。
- 已完成人审通过率 = 通过数 / (通过数+不通过数)；待审率另报。
- 基础错误率 = 因错链/词品不符/错货源/已做/无独立需求重复而被否决的唯一候选数 / 已完成人审候选数。多原因不重复计数。
- 数据补齐率 = 在约定观察期内完成预登记缺失字段的候选数 / 进入补证队列的候选数。
- 开发转化率 = launch通过数 / 进入研究队列的候选数；另报launch通过/开发终审提交数。
- 单合格候选研究耗时 = 同批全部研究耗时 / launch通过数；分母0时为不可计算，不写0。

旧50款仅用于校准/回归。下一批采用预先定义的新样本、固定研究预算和观察期，并报告来源、方向分布和全部去向；条件许可时旧/新规则对同批输入盲评。提交量下降、改变状态名称或删除失败样本不能当提升。未经新样本实测不承诺提高到某个百分比，也不能把技能规则校验称为实盘回测完成。

## 6. 批量候选与采购交接回归

- 用户要求50个深筛候选，当前只有11个完成证据：如实报告11和39个缺口并继续扩池；不得把39个发现线索改名为深筛通过。若用户要求的是50个询价候选，则只有通过询价前经济性上限筛选的候选计数。
- 某英国Offer售价高于USD 4.99等值，但扣除VAT、固定15%佣金、保守FBA及其他非采购成本后，即使采购价为0也达不到30%贡献利润率：不进入采购表，`PREQUOTE_ECONOMICS_WEAK`。
- 某候选反推采购空间为CNY 18，产品为常见塑料注塑小件、标准pack、无新模具/认证且包装负担低：即使没有1688链接，也可标记采购空间可能实现并进入人工询价；profit_validation_status仍为待人工询价。若同样CNY 18对应复杂金属组件、大pack、定制电子或新增认证，则应标记明显不可实现或边界，不进入A档。
- 通过增加pack可把售价从低价带提高到目标带，但目标pack没有自身销量、自然流量或单位价值证据：不得仅为抬价组合；pack市场待补。
- 采购填写“2元”但未说明是单件还是20件整包：`QUOTE_UNIT_OR_PACK_MISMATCH`，实际利润数据异常；不得默认乘20或直接按2元整包计算。
- 50行采购表中候选ID唯一但ASIN有重复，且重复行只是同父体同配置：不得宣称50个独立候选；先按机会和精确Offer去重。
- 表格存在空白/不可见表头、公式错误或模拟输入后状态不联动：交付检查不通过，先修复再交付。
- 二次核算中7款直接通过、4款仅因费用或类目条件成立才可能通过：开发复核数只能先计7；条件4款保持待补，不能并入利润通过。
- 同结构螺丝100PCS包装重420g、200PCS为760g，且两行均为精确子Offer同层级数据：可反推单位增量3.4g、基础包装80g，150PCS基准毛重590g；仍须给区间并在人工回填后重算，不能写成实测。
- 100PCS杯子包装高30cm、200PCS高42cm：套叠结构只按高度增量建模，长宽不得机械翻倍；若无法确认套叠方式，降低置信度并扩大保守体积。
- 单一竞品仅显示“item weight”，没有package dimensions：置信度D或待补，不得以该净重生成正式询价行。
- 保守包装情景跨越2kg或FBA/头程路线边界：同时计算相邻两档并以较高成本情景判断`quote_ready`；不能只用基准情景保留候选。
- 竞品包装估算显示有空间，供应商最终包装实测使FBA升档且利润率降到29%：重新路由后实际利润不通过；不得沿用询价前采购空间结论。
