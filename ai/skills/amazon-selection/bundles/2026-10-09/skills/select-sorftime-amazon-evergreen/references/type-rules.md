# 日常品类型规则

方向规则版本：`evergreen-demand-v0.7.0`。公共阈值版本：`selection-gates-v0.10.0`。历史产品回测前均为初始阈值。

## 1. 类型通过条件

- 连续证据窗口`>=12个月`。
- 有效需求月`>=10个月`。
- Top3月份需求占全年`<=45%`。
- 至少1个核心词、2个相关词和3个非Amazon/非强品牌代表ASIN的趋势相互支持。
- 需求不是由断货恢复、促销、广告集中、合并变体或单一老链接清仓制造。

市场不足3个合格代表ASIN时为人工复核，不得为了凑样本混入不同购买意图。

## 2. 有效需求月

一个月同时满足：

1. 市场需求不低于全年Top3需求月份中位数的20%。
2. 核心词趋势与多个可比ASIN或类目需求相互支持。
3. 不是仅由1–3件尾量、断货、上新、促销或价格跳水造成的假低谷/假高峰。

自身月销`>=30`由共享市场模块使用完整新品队列另行验证，不混入`type_decision`。类型通过但新品队列不足时，`market_decision=待补`。

## 3. 改类与异常

- 4–9个有效月、窗口可解释且跨周期重复：建议季节品，`RECLASS_SEASONAL`。
- 节日用途及节前曲线主导：建议节日品，`RECLASS_HOLIDAY`。
- 非周期短期暴涨且与热门母体配件需求相关：建议热点配件，`RECLASS_HOT_ACCESSORY`。
- 有效月>=10但Top3月份占比>45%：人工复核，`FAKE_EVERGREEN`。
- 父体全年稳定而目标子体只在少数月份销售：不通过，`VARIATION_CONTAMINATION`。
- 历史不足12个月或核心词趋势缺失：待补，`INSUFFICIENT_HISTORY`。

## 4. Sorftime证据

类目使用`category_report`、`category_trend`、`category_keywords`及必要历史快照；关键词使用`keyword_detail`、`keyword_trend`和自然/广告结果；商品使用`product_search`、详情、报告、趋势、变体和流量词。选品阶段不核对1688，按目标配置反推采购空间并判断可能性。

先完成精确市场预检，再抓全年趋势。核心词有12个月历史只证明词有历史，不能替代相关词、代表ASIN、自然入口和精确市场证据。市场自动通过条件缺失时按共享组合证据判断是否仅能进入受控试询；日常类型本身仍必须满足第1节，不因市场样本不足降低10个有效月要求。

## 5. 结论与原因码

| 情况 | `type_decision` |
|---|---|
| 12个月以上、有效月>=10、集中度及多源一致 | 通过 |
| 历史或关键趋势缺失 | 待补 |
| 断货/促销/变体污染但可核验 | 人工复核 |
| 符合另一类型 | 建议改类 |
| 有效月<10且无合理改类 | 不通过 |
| 月数、日期、单位或父子体冲突 | 数据异常 |

原因码：`PASS_EVERGREEN`、`INSUFFICIENT_HISTORY`、`ACTIVE_MONTHS_LT_10`、`FAKE_EVERGREEN`、`CROSS_SOURCE_MISMATCH`、`STOCKOUT_DISTORTION`、`PROMO_DISTORTION`、`VARIATION_CONTAMINATION`、`RECLASS_SEASONAL`、`RECLASS_HOLIDAY`、`RECLASS_HOT_ACCESSORY`。

## 6. 回归用例

1. 24个月、每滚动12月有11个有效月、Top3月份40%、多词多ASIN一致：类型通过。
2. 12个月均有销量但4–9月贡献85%，其余月每月1–3件：不能通过日常品；窗口复现时建议季节品。
3. 恰好10个有效月通过；9个不得因接近阈值通过。
4. 只有Listing年龄和年度总销量：待补。
5. 类型通过但新品队列被高销量截断：市场待补。
6. Top1品牌18%、Top3品牌34%：分散/蓝海标签不通过；不能仅由34%否决市场。继续验证头部控制、独立新品自然位、T预测及目标方案；数据不足则待补，不能由类型或总分直接放行。
